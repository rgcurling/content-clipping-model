# Content Clipping Model

Automatically fetch top clips from Twitch or Kick, generate AI-powered captions with Claude, and post them to TikTok — or prepare them locally with burned-in captions ready for manual upload.

## About

This tool automates the content clipping pipeline for streamers and content creators. It pulls the most-viewed clips from the last 7 days from Twitch or Kick, ranks them by view count, and either posts them directly to TikTok with AI-generated captions or burns captions into the video files for manual distribution.

Captions are generated by Claude (via the Anthropic API) and tailored for TikTok engagement.

## Features

- **Twitch clip fetching** — Authenticates with the Twitch Helix API and pulls all clips from the last 7 days, ranked by view count
- **Kick clip fetching** — Scrapes the Kick public API (no credentials required) with the same 7-day window and ranking
- **AI caption generation** — Uses Claude Haiku to write punchy, platform-appropriate captions
- **TikTok posting** — Full OAuth2 + PKCE flow to upload clips directly to TikTok via the Content Posting API
- **Local clip preparation** — Downloads clips and burns Gen Z-style captions into the video using FFmpeg, outputting ready-to-upload `.mp4` files

## Getting Started

### Prerequisites

- Python 3.11+
- [FFmpeg](https://ffmpeg.org/download.html) installed and on your `PATH` (required for `prepare_clips.py`)
- A [Twitch Developer App](https://dev.twitch.tv/console/apps) (for Twitch fetching)
- A [TikTok Developer App](https://developers.tiktok.com/) with `video.upload` and `video.publish` scopes (for TikTok posting)
- An [Anthropic API key](https://console.anthropic.com/) (for caption generation)

### Installation

```bash
git clone https://github.com/your-username/content-clipping-model.git
cd content-clipping-model
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### Configuration

Copy `.env.example` to `.env` and fill in your credentials:

```bash
cp .env.example .env
```

```env
TWITCH_CLIENT_ID=your_client_id_here
TWITCH_CLIENT_SECRET=your_client_secret_here

TIKTOK_CLIENT_KEY=your_client_key_here
TIKTOK_CLIENT_SECRET=your_client_secret_here

ANTHROPIC_API_KEY=your_api_key_here
```

Kick does not require credentials.

## Usage

### 1. Fetch clips

**From Twitch:**
```bash
python src/main.py --streamer <twitch_login> [--output clips.json] [--limit 10]
```

**From Kick:**
```bash
python src/main_kick.py --streamer <channel_slug> [--output clips.json] [--limit 10]
```

Both commands write a ranked `clips.json` file (see `config.example.json` for the output schema).

### 2a. Post to TikTok

Reads `clips.json`, generates captions via Claude, and uploads directly to your TikTok account. Opens a browser window for OAuth on the first run; the token is cached for 23 hours.

```bash
python src/post_to_tiktok.py [--input clips.json] [--count 3]
```

### 2b. Prepare clips locally

Downloads clips, burns a short Gen Z caption into each video with FFmpeg, and saves the results to `./output/`.

```bash
python src/prepare_clips.py [--input clips.json] [--count 3]
```

Output files are named `<streamer>_<clip_id>.mp4`.
