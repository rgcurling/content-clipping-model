# Documentation

## Scripts

### `src/main.py` — Fetch Twitch Clips

Authenticates with the Twitch Helix API using client credentials and fetches all clips created in the last 7 days for a given streamer. Results are deduplicated and ranked by view count.

**Arguments:**
| Flag | Default | Description |
|------|---------|-------------|
| `--streamer` | *(required)* | Twitch login name |
| `--output` | `clips.json` | Output file path |
| `--limit` | all | Max clips to include |

**Required env vars:** `TWITCH_CLIENT_ID`, `TWITCH_CLIENT_SECRET`

---

### `src/main_kick.py` — Fetch Kick Clips

Fetches clips from the Kick public API. No credentials needed. Filters to the last 7 days client-side and ranks by view count.

**Arguments:**
| Flag | Default | Description |
|------|---------|-------------|
| `--streamer` | *(required)* | Kick channel slug |
| `--output` | `clips.json` | Output file path |
| `--limit` | all | Max clips to include |

**Required env vars:** none

---

### `src/post_to_tiktok.py` — Post to TikTok

Reads `clips.json`, generates a TikTok caption for each clip using Claude Haiku, downloads the video with `yt-dlp`, and uploads it via the TikTok Content Posting API.

OAuth2 with PKCE is used for authentication. A browser window opens on the first run; the token is cached in `.tiktok_token` for 23 hours.

**Arguments:**
| Flag | Default | Description |
|------|---------|-------------|
| `--input` | `clips.json` | Clips data file |
| `--count` | `3` | Number of clips to post |

**Required env vars:** `TIKTOK_CLIENT_KEY`, `TIKTOK_CLIENT_SECRET`, `ANTHROPIC_API_KEY`

---

### `src/prepare_clips.py` — Prepare Clips Locally

Downloads clips and burns a short Gen Z-style caption (generated by Claude Haiku) into the bottom of each video using FFmpeg. Output files are saved to `./output/`.

**Arguments:**
| Flag | Default | Description |
|------|---------|-------------|
| `--input` | `clips.json` | Clips data file |
| `--count` | `3` | Number of clips to prepare |

**Required env vars:** `ANTHROPIC_API_KEY`

**System requirement:** `ffmpeg` must be installed and on `PATH`.

---

## Output Schema

Both `main.py` and `main_kick.py` produce a `clips.json` with this structure. See `config.example.json` for a concrete example.

```json
{
  "generated_at": "ISO 8601 timestamp",
  "streamer_login": "channel name",
  "broadcaster_id": "platform user ID",
  "period": { "start": "...", "end": "..." },
  "total_clips": 42,
  "clips": [
    {
      "clip_id": "...",
      "title": "...",
      "url": "...",
      "thumbnail_url": "...",
      "view_count": 9821,
      "duration": 30.0,
      "created_at": "...",
      "creator_name": "..."
    }
  ]
}
```
